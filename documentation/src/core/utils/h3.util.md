# `src/core/utils/h3.util.ts`

## Role

Thin helpers around **H3** (hexagonal hierarchical geospatial indexing).

## Functions

| Function | Description |
|----------|-------------|
| `h3Cell(lat, lng, res = 8)` | `latLngToCell` — H3 index for a coordinate at resolution `res`. |
| `neighbors(h3Index)` | Cells in grid disk radius 1 excluding the center cell — used for spatial adjacency (e.g. pricing/telemetry). |
